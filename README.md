# おしりオフィス

一人で遊ぶブラウザゲームです。公開リポジトリ名: `new-oshiri-office`。

公開ゲーム: https://gameyyyyyyyyy.github.io/new-oshiri-office/

## 遊び方

ローカル確認は `python3 -m http.server 8000` で配信し、ブラウザで `http://localhost:8000/` を開きます。HTMLファイルの直接起動ではモジュールや素材を読み込めません。

## 保存・共有

記録はブラウザ内に保存されます。保存できない環境でも一時的に遊べます。設定画面からこのゲームの保存データだけを削除できます。共有URLは配信先から自動生成されます。読み上げには端末内の日本語音声だけを使います。

## 検証と配信

Node.js 24で `node --test tests/*.test.mjs`、`node tools/build.mjs` を実行します。追加のnpm依存はありません。`_site/` が配信用で、開発ファイルやGit情報はコピーされません。

GitHub Pagesは「Deploy from a branch」で `gh-pages` ブランチの `/ (root)` を公開します。`main` はソース保管用です。更新時はテストとビルドを行い、`_site/` の中身（`.nojekyll` を含む）を `gh-pages` にコミットしてpushしてください。`main` の変更だけではゲームは更新されません。
